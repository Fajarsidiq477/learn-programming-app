If – Else

If – else is how your app makes a decision.

What is a decision?

You make decisions all day: “If it is raining, I bring an umbrella. Else, I leave it at home.” An app does the same thing. It asks a yes-or-no question, then chooses which blocks to run.

  • If the password is correct, open the next screen. Else, show “Wrong password”.
  • If the score is 75 or more, show “Passed”. Else, show “Try again”.

Conditions: the yes-or-no question

The question is called a condition. Its answer is always a boolean: true or false. You build conditions with these blocks:

Where to find the blocks

Open the Blocks view, then click Built-in → Control. The if – then block is at the top. Control blocks are yellow-brown.

1. If – then

If the condition is true, the blocks inside then run. If it is false, they are skipped and nothing happens.

if get global score ≥ 100
then
set Label1 . Text to " You win! "

2. If – then – else

Now there are two paths. If the condition is true, the then part runs. If it is false, the else part runs. Exactly one of them always runs.

How to add else: click the small blue gear on the if block. A little window opens. Drag else (or else if) under the if inside that window.

when ButtonCheck .Click
do
if TextBoxScore . Text ≥ 75
then

When there are more than two possible results, add else if with the blue gear. The app checks the conditions from top to bottom and runs only the first one that is true. After that it skips all the rest.

Common mistakes

  • Wrong order. If you check ≥ 75 before ≥ 90, a score of 95 gets a B, because the first true condition wins. Check the strictest condition first.
  • Using several separate if blocks instead of else if. Separate if blocks are all checked, so more than one can run and the last one overwrites the others.
  • An empty socket. The if block needs a condition plugged in. An empty socket shows a warning and the app will not work.
  • Forgetting else. Without it, nothing happens when the condition is false, and the user gets no feedback.

Check your understanding

1. What kind of value does a condition give?

A boolean: true or false.

2. In an if – then – else block, can both parts run in the same click?

No. Exactly one part runs: then when the condition is true, else when it is false.

3. age is 15. Is age ≥ 13 and age < 15 true or false?

False. 15 ≥ 13 is true, but 15 < 15 is false, and and needs both sides to be true.

4. Using the grade example above, what grade does a score of 75 get?

B. 75 ≥ 90 is false, then 75 ≥ 75 is true.
